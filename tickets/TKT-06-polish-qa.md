## Acceptance criteria

- [ ] Settings → Appearance shows two rows: "UI Theme" (Plex / Original toggle) and "Accent" (Moonfin Purple / Plex Gamboge / Jellyfin Indigo / Custom hex).
- [ ] Selecting a preset writes both `settings.uiThemePreset` and updates `--accent` + `--accent-2` on `:root` immediately.
- [ ] Custom hex option uses the existing `focusColor` hex input — no duplicate input.
- [ ] Existing `--accent-color` (from `settings.focusColor`) stays in sync with the selected preset so the upstream UI continues to work when `uiTheme === 'original'`.
- [ ] Visual QA pass on all three views (Browse, Details, Library):
  - Focus rings reach every interactive element.
  - D-pad traversal order matches reading order.
  - Active and focused states render distinctly.
  - No focus dead zones.
- [ ] Performance audit on all Plex stylesheets:
  - No `transition: all`. Grep should return zero matches in `styles/plex-ui/` and any `.module.less` under `components/plex-ui/` and `views/plex-ui/`.
  - No `backdrop-filter`. Grep should return zero matches in the same paths.
  - `will-change` appears only inside `[data-near-focus="true"]` selectors or equivalent scoped patterns; never on a card row root.
- [ ] `.wgt` files generated by both `npm run build:tizen` and `npm run build:tizen:legacy` are clean, with no warnings related to the Plex views.
- [ ] `views/plex-ui/README.md` contains: a screenshot strip referencing the three mockups, a "How to toggle back to the original UI" section, and a list of the accent presets.
- [ ] PROGRESS.md updated with TKT-06 ticked.
- [ ] All six previous tickets' `Status: ⬜` updated to `Status: ✅` in their respective files.

## Technical notes

- Settings view: read the existing Settings file structure first. The Settings view almost certainly renders sections as a configured list — add one new section entry rather than editing render code directly.
- AccentPicker is a row of 4 chips (3 presets + Custom). Custom chip opens the existing hex input modal — reuse, do not duplicate.
- When `uiTheme` flips between Plex and Original, the user should see the change without a reload. Confirm this works.
- Document the Jellyfin 2 Samsung deployment path in the README (I deploy via Jellyfin 2 Samsung — link to that app in the README).

- Changing any visual decision from earlier tickets — this phase is polish, not redesign.
- Light theme — would require a new ADR; not in this ticket.
